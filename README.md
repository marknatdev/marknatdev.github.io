# marknatdev.github.io

Portfolio website of Mark (marknatdev), live at **https://marknatdev.github.io**.

Achievements, selected projects and contact links, in English and Thai. Built with React, Vite, Tailwind CSS and TypeScript; every push to `main` deploys to GitHub Pages through `.github/workflows/deploy.yml`.

```bash
npm install
npm run dev      # local preview
npm run build    # production build in dist/
```

Award photos go in `public/achievements/` (see the README there).
